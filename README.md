# Ummi Homestay Website

Website statik untuk GitHub Pages.

## Cara terbitkan
1. Cipta repository baharu di GitHub, contoh `ummi-homestay`.
2. Upload semua fail dan folder dalam pakej ini.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, kemudian Save.
6. GitHub akan beri pautan website.
